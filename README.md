### 👋 About Me

I'm a **Java Backend Engineer** currently interning at **ValueMore Tec LLP**, where I build REST APIs and microservices for a high-scale booking/payment/notification platform — and I'm presently deep in **system design and scalability**: caching strategy, query optimization, and service boundaries for high-traffic systems.

Outside my day-to-day stack, I like stretching into different domains — an exoplanet-detection ML model, a PHP certificate-management dashboard, e-commerce storefronts. I'd rather understand a problem end-to-end than stay boxed into one layer of the stack.

- 🏭 Built and shipped **two production backend systems for real clients** — a milk-delivery subscription platform (**FreshMilk**) and an e-commerce platform (**Knr Foods**) — both live today, together serving 750+ users.
- 🧪 Currently building **f3_naturals** — a new project in early demo stage.
- 🎯 Learning focus right now: system design, scalability patterns, distributed caching.
