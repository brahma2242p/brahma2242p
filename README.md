## 👋 About Me

I'm a **Java Backend Engineer** with hands-on production experience building REST APIs, backend services, and microservices using **Java 17/21, Spring Boot 4.0, Spring Security, Hibernate/JPA, PostgreSQL, MySQL, and Redis**.

Currently working at **ValueMore Tec LLP**, contributing to an enterprise microservices platform spanning **booking, payment, notifications, and partner management**. My current engineering focus includes **system design, scalability, caching strategies, database query optimization, service boundaries, API design, and production reliability**.

I have also independently built and deployed **two production backend systems for real clients**, serving **750+ combined users**, with integrations across payment, shipping, cloud storage, and customer communication platforms.
